# App Store screenshots — V0.92

App Store Connect requires screenshots at every iPhone size the app
supports. Without them the submission is rejected.

This directory holds the rendered screenshots for V0.92, generated by
`scripts/make-screenshots.py` from four source captures of the V0.88
build of Games Room on the iPhone 17 Pro Max simulator (iOS 26, Xcode
27). The script:

1. Resizes each source capture (1320 × 2868) to the target iPhone size,
   preserving aspect ratio (top-cropping the home-indicator area).
2. Adds a centred caption strip at the top in the brand background
   color (`Theme.Palette.background` ≈ rgb(8, 8, 8)) using Fraunces
   (the V0.8 display font), parchment text.
3. Writes a PNG at `quality=100` to the matching `iphone-X.X/` folder.

Each folder contains the same four shots, in this order (Apple's
App Store Connect screenshot scroller respects the file order):

1. **01-signin.png** — *Sign in*
   The cold-start surface. Apple Sign-in prompt over the

   tone before any feature chrome appears.

2. **02-rooms.png** — *Your rooms*
   The persistent home. Three seeded rooms (Carwoola Crew live,
   Pluto Chess Sundays, Felt Faction) with the live-session dot on
   the active room, "+" create-room and "+person" join-room
   affordances in the trailing toolbar, and the segmented Rooms /
   Settings tab bar at the bottom.

3. **03-casino-live.png** — *Tonight's game*
   The room-detail surface in `.tonightEvent` mode. WitnessSlot
   "The night has started" hero with the brass primary
   "Withdraw to play" CTA, secondary "Count your CAH cards"
   affordance, the Carnegie praise-first notification opt-in prompt
   (V0.84), the Standings leaderboard with chip counts
   (Host 1,200 / Alex 980 / Sam 740 — sessions played + last delta),

   The App settings sheet. Display name editor, "Log out"

## How the source captures were taken

```bash
# Sync the worktree to the Mac Studio (Xcode 27 host)
git worktree add "/path/to/.worktrees/t_f86ae80f" feat/v092-screenshots
# copy gitignored Config.xcconfig from the main worktree

# Build (Debug; CODE_SIGNING_ALLOWED=NO so simulator builds skip the
# codesign gate per failure-mode #8 in ios-build-verification-outside-xcode)
xcodebuild -project GamesRoom.xcodeproj -scheme GamesRoom \
  -destination "platform=iOS Simulator,name=iPhone 17 Pro Max" \
  -configuration Debug build CODE_SIGNING_ALLOWED=NO

# Boot + install
xcrun simctl boot "iPhone 17 Pro Max"
xcrun simctl install booted "/path/to/.app"

# Cold launch with the screenshot bypass (see "Screenshot mode" below)
xcrun simctl launch booted com.gamesroom.app \
  -screenshots-bypass-auth \
  -screenshots-tab=rooms|settings \
  -screenshots-screen=room-detail
sleep 7
xcrun simctl io booted screenshot /tmp/gr-shot-NN.png
```

## Screenshot mode (V0.92 launch arguments)

V0.92 adds three Debug-only launch arguments used to drive the
screenshots. None of them affect Release builds.

| Argument                          | Effect                                                                                  |
|-----------------------------------|-----------------------------------------------------------------------------------------|
| `-screenshots-bypass-auth`        | Swap `LiveRoomStore` for `InMemoryRoomStore.shared` and inject a stub `currentUser` so the in-app surfaces render without going through Apple Sign-In. Also nudges the seeded `carwoolaEvent.playedAt` into the past so the room surfaces the `.tonightEvent` casino state. |
| `-screenshots-tab=rooms\|settings`| Set the initial `TabView` selection on launch.                                          |
| `-screenshots-screen=room-detail` | Push the first seeded room onto the iPhone `NavigationStack` on first appearance.       |

All three live under `#if DEBUG` in `GamesRoom/`, `AuthService.swift`,
`RoomPage.swift`, `InMemoryRoomStore.swift`, and `GamesRoomApp.swift`.
Production binaries never see these branches.

## Regenerating

```bash
python3 scripts/make-screenshots.py
```

Re-capture sources first if the UI has shifted; the four
`.sshot-NN.png` paths at the top of the script are the inputs.

## Out of scope (V0.92)

- App preview videos — separate decision; not required for
