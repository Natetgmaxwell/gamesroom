## Deliverables

### 1. Migration `Supabase/migrations/054_round_delete_and_correction_fix.sql`

Three changes, one file:

**a) Fix correction double-count in `record_round_score`** (bug in migration
042). When a round is re-submitted, the upsert on
`(room_id, event_id, round_index)` replaces the row, but the old entries'
deltas were never reversed from `room_memberships.season_score` — the new
deltas are added on top, inflating totals. Fix: before the upsert, read the
existing row's `entries`; if present, reverse each old delta
(`season_score = season_score - old_delta`) before applying the new deltas.
Signature unchanged → `create or replace` (grant survives).

Order inside the function:
1. auth checks (unchanged)
2. `select entries into v_old_entries` from the existing row (null for a fresh round)
3. upsert the round_submissions row (unchanged)
4. reverse old deltas: loop `jsonb_array_elements(coalesce(v_old_entries, '[]'::jsonb))`, subtract each `points_delta` from the member's `season_score`
5. delete old transactions for the round (unchanged)
6. insert new transactions + apply new deltas (unchanged)

**b) New `delete_round_score(p_room_id uuid, p_event_id uuid, p_round_index integer)` RPC.**
Returns void. Host-only (same room-owner check as `record_round_score`).
Idempotent: no row for the round → return without error. Behavior:
1. read the round's `entries`; if null, return
2. reverse each delta from `season_score` (same loop as the fix above)
3. delete the round's transactions (`room_id`, `session_id`, `meta->>'round_index'`)
4. delete the `round_submissions` row
Grant execute to `authenticated`.

**c) Extend `get_event_rounds` with `correction_of`.** DROP + CREATE (RETURNS
TABLE column list changes — Postgres error 42P13). Add `correction_of uuid` to
the returns table and select `rs.correction_of`. Grant execute.
