## Intent

The no-show tax stops auto-firing. At session start the HOST sees a
mascot-voiced prompt per claimed-but-absent member, with three choices:
Apply / Skip (texted) / Skip (away). The host always decides; the system
never decides alone. Carnegie 3.1 (don't argue) + 4.5 (save face).

Substrate line: the forfeited chip moves into the NEXT POT (public next-pot
money), never against the absent member's social standing. Drowning stays
private. The host prompt is the only moment the no-show touches the room.

## Design decisions (locked for this task)

D1. Four settings columns on `public.rooms`, mirroring 081:
    - `no_show_tax_amount integer not null default 200`, bounded 0..1000
    - `no_show_tax_trigger text not null default 'prompt'`, check in
      (auto, prompt, manual)
    - `no_show_tax_grace_minutes integer not null default 10`, bounded 0..120
    - `no_show_tax_destination text not null default 'next_pot'`, check in
      (next_pot, host_charity_pot, split)
    The `room.seatDepositAmount` (043) stays untouched — it is the deposit
    that gets HELD at claim; the tax is what forfeits at no-show. Room
    defaults: amount 200 CC, trigger prompt, grace 10 min, destination
    next_pot. `auto` = legacy behaviour (forfeit at settle without
    prompting) and `manual` = host applies from Operations whenever.

D2. Migration 082_no_show_tax_settings.sql:
    1. Four columns + checks + defaults (idempotent alter, DO block for
       constraints mirroring 081).
    2. `update_room_settings` dropped (13-arg) and recreated as 17-arg
       (adds p_no_show_tax_amount, p_no_show_tax_trigger,
       p_no_show_tax_grace_minutes, p_no_show_tax_destination) — drop old
       overload first, same convention as 061/081. Returns the four new
       columns too.
    3. `get_my_rooms` re-created returning the four columns.
    4. RPC `list_no_show_candidates(p_event_id)` — host-only
       (r.created_by = current_user_id()), SECURITY DEFINER,
       search_path=public. Returns one row per claimed RSVP whose owner
       has no transactions row for the event: user_id, display_name,
       tax_amount (rooms.no_show_tax_amount), within_grace boolean
       (now() < played_at + grace minutes). No writes.
    5. RPC `apply_no_show_tax(p_event_id, p_user_id, p_reason)` —
       host-only. Forfeits exactly one held seat deposit of the room's
       `no_show_tax_amount` (uses the deposit row from 043 if present —
       inserts a transactions row kind='no_show_tax' amount = tax amount
       with meta {reason, deposit_id}; destination honoured:
       next_pot → bank to next event's pot (meta flag + membership
       balance untouched); host_charity_pot → same transaction, meta
       destination='host_charity_pot'; split → meta destination='split'.
       Idempotent per (event, user): if a no_show_tax transaction
       already exists for the pair, return success without double-tax.
       Honour trigger: if trigger='manual', reject with errcode 42501
       'Tax is manual — apply from Room Settings'? NO — the prompt is
       allowed regardless; manual means the host was never prompted but
       CAN still apply. Keep apply path trigger-agnostic.
    6. RPC `skip_no_show_tax(p_event_id, p_user_id, p_reason)` — host-only.
       Inserts transactions row kind='no_show_tax_waiver', amount 0, meta
       {reason: 'texted'|'away'}. Idempotent per (event, user).
    7. comment on function for each new RPC; grants to authenticated.
    8. notify pgrst 'reload schema'.

    Destination semantics (locked): the tax chips are RECORDED as a
    public ledger row (kind='no_show_tax', member_id = the no-shower,
    amount = tax) and applied to the next event's pot at its creation —
    the client can read them via the existing ledger surfaces. No
    membership balance changes for the no-shower at apply time when a
    seat deposit was held (the deposit already debited the balance at
    claim per 043). When NO deposit row exists (claim without deposit),
    the apply RPC debits membership points_balance by tax amount (the
    tax stands alone) and records the transaction.

D3. Swift `NoShowTaxSettings` — add to `GamesRoom/Models/SeatDeposit.swift`:
