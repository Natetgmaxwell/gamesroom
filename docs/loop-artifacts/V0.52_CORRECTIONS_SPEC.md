# V0.52 — Chips withdrawn rename + pack-explicit settle context

## Goal

Three user corrections on the V0.51 chips-on-the-table + settle flow.
All UI-layer — no schema change (migration 065 stays as-is, applied live).

1. Rename "Chips on the table" → "Chips withdrawn"; drop the bank
   balance column entirely (host AND member). Working-hand pts only
   per member row. Caption under the header must frame working hands
   as chips MOVED from the bank, not balances.
2. Make the settle surface pack-explicit so the user can tell casino
   settle from CAH settle at a glance — CTA labels name the pack, and
   the sheet that opens declares the pack + working-hand/card context
   in its first screen.
3. Verify the withdraw guardrail server + client side (read-only; no
   change unless broken).

## Design decisions (owner: orchestrator — do not relitigate)

1. **Bank column removal:** delete the `if isHost { Text("\(hand.pointsBalance) bank") }`
   block from `ChipsOnTableSection` entirely. `WorkingHand.pointsBalance`
   + the RPC column are NOT removed (already live, harmless). Section
   shows only display name + working-hand pts per row, any role.
2. **Caption under the header:** add a muted caption below the
   "Chips withdrawn" title: `"Chips moved from the bank for tonight"`.
   NOT "balances". This preserves the join_starting_bonus context
   without rendering a number per member.
3. **Pack-named CTA labels** (WitnessSlot `scanTitle` at all 3 call
   sites): casino → `"Settle casino chips"`; CAH → `"Count your CAH
   cards"`. Also update WitnessSlot's `scanTitle` default (currently
   "Scan your chips") to `"Settle casino chips"` so the default matches
   the pack-named convention if a future call site omits it.
4. **ChipScanSheet context header:** in `cameraView`, above "Point at
   your chip stack", add a header line naming the pack + working hand
   using the existing `withdrawn` param:
   `"Settling your Casino hand — you brought \(withdrawn) pts. Scan what's left on the table."`
   This is the first thing the member sees when the sheet opens, so
   the pack is unambiguous within 1s.
5. **CAHCardScanSheet context header:** above "Point at your stack of
   black cards", add: `"Counting your CAH cards — cards you won this session. Each black card is a point."`
