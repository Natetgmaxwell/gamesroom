## Slice 1 — SQL (migration 083)

Create `Supabase/migrations/083_tonight_star_and_member_notes.sql` (match 051's
comment style, header explains C2+C5):

1. Table `tonight_star_picks` (C2 — persists the HOST PICK, not a vote):
   - id uuid pk, event_id uuid not null references events(id) on delete cascade,
     unique(event_id) — one pick per session
   - room_id uuid not null references rooms(id) on delete cascade
   - member_id uuid not null references users(id) on delete cascade
   - override_category text not null check (in ('best_play','good_sport',
     'held_the_room','showed_up','custom'))
   - custom_text text
   - created_at timestamptz not null default now()
   - RLS: members read (is_room_member); NO direct writes (with check (false))
2. Table `room_member_notes` (C5 — one-line drop):
   - id uuid pk, room_id, member_id (references users), season_id uuid
     (nullable, references seasons), note_text text not null,
     created_at, consumed_by_host_at timestamptz
   - RLS: members read own rows in their rooms; host reads room's rows;
     no direct writes (RPC only). No reply/thread columns — one-way.
3. RPC `set_tonight_star_pick(p_event_id, p_member_id, p_override_category, p_custom_text)`
   — host-only (r.created_by = current_user_id() via event→room), upsert on
   unique(event_id). Validates custom ⇒ custom_text non-empty; nulls it otherwise.
4. RPC `get_tonight_star_card(p_event_id)` returns table(member_id,
   member_display_name, override_category, custom_text, source) — source =
   'host_pick' when a pick row exists, else falls through to the 067 chip-swing
   computation (reuse the same query body) with source='chip_swing'. Empty when
   neither. Membership-guarded (mirror 067's exists clause).
5. RPC `submit_member_note(p_room_id, p_note_text)` — member writes own note.
   Guards: caller is room member; trim non-empty; ≤500 chars; rate: at most one
   note per member per calendar day (soft) — reject duplicates same-day with a
   clear errcode. Sets season_id from the room's active season (may be null).
6. RPC `get_unconsumed_member_notes(p_room_id)` — host-only; returns notes where
   consumed_by_host_at is null, oldest first, joined with display names.
7. RPC `mark_member_notes_consumed(p_room_id, p_note_ids uuid[])` — host-only;
   stamps consumed_by_host_at = now() on the listed notes.
8. `drop function if exists` guards not used in this repo — match existing style
   (create or replace + create table if not exists). Grants to authenticated.

Down note: single-purpose migration, rollback = drop the two tables + five RPCs.

map, mascot register, names the behaviour not the stat (praise-first per C4):
- best_play: "{winner} played the night's best hand. The host saw it; the table knows."

personality/ideology matrices or `.goodSport`/`.tonightStar` kind cells.
