## Changes (apply exactly)

### 1. Add a `roomHasCAHPack` computed property to `RoomDetailView`

Add near `liveRoom` (after line 173). Empty cache falls back to true (all packs
installed), matching the `RoomSettingsSheet.packs` convention:

```swift
/// V0.66 — whether the room has the CAH pack installed. Empty
/// cache means no explicit overrides → all packs installed
/// (matches the Operations sub-sheet convention). Drives the
/// secondary "Count your CAH cards" CTA on every active event.
private var roomHasCAHPack: Bool {
    let enabled = roomService.cachedRoomPacks(roomId: room.id)
    if enabled.isEmpty { return true }
    return enabled.contains(CardsAgainstHumanityPack.slug)
}
```

### 4. Do NOT render casino settle on CAH events (decision, documented)

The user's ask is CAH-from-anywhere. The reverse (casino settle secondary on a
CAH event) is NOT implemented. Rationale: `SettleCasinoSheet` requires a casino
working hand (`withdrawn`), which does not exist on a CAH event — the CTA would
open a sheet with `withdrawn: 0`, a meaningless no-op. The CAH settle is
pack-independent (count cards), so it makes sense everywhere; casino settle is
tied to a casino working hand, so it only makes sense on casino events. This is
documented in the spec.
