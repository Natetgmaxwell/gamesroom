# V0.34b dashboard-wiring loop (self-contained)

You are wiring the in-session round logging into the iPad host scoring dashboard
in the Games Room repo. Work in the current directory (repo root). Read
`V0.34B_DASHBOARD_WIRING_SPEC.md` in this directory first — it is the
authoritative spec; this file is the loop contract.

## Task

Wire the round-logging core (already landed) into `HostScoringDashboard.swift`:
round auto-increment seeded from the actual log, the session timeline embedded,
and correct/undo for past rounds.

## Hard constraints

1. **Edit scope: ONE file — `GamesRoom/Views/HostScoringDashboard.swift`.**
   Do NOT touch any other file. `RoomDetailView.swift` is a flagged hotspot
   (three sibling tasks collided there) — no edits. No pbxproj edits (the
   timeline view is already registered).
2. **The log is the source of truth for the round index.** After every save,
   delete, or edit-cancel, reseed `roundIndex` from `rounds.nextRoundIndex`
   (the `Array<EventRound>` extension in `GamesRoom/Models/EventRound.swift`).
   Remove the current `roundIndex += 1` line in `save()`.
3. **Theme tokens only.** `Theme.Palette`, `Theme.Typography`, `Theme.Layout`,
   `Theme.Icon`. No new tokens, no hardcoded colors/fonts/sizes. Match the
   file's existing style (MARK sections, doc comments on new private funcs,
   reuse `errorMessage` for failures).
4. **No dead code, no TODOs.** Keep the existing structure: header, chip grid,
   submit bar, [timeline], standings strip — dividers between each.

## Changes (from the spec)

1. `@State private var rounds: [EventRound] = []` and
   `@State private var editingRound: EventRound?`.
2. `.task` that loads rounds and seeds `roundIndex = rounds.nextRoundIndex`.
3. After successful save: reload rounds, reseed index, clear selection and
   `editingRound`.
4. `SessionRoundTimeline` between submit bar and standings strip, wrapped in a
   vertical ScrollView capped at `maxHeight: 240` (the timeline can grow).
5. Edit flow: `startEditing(_:)` sets `editingRound`, `roundIndex`, and
   selection from the round's entries; header shows "Editing round N" + Cancel
   while editing; `save()` passes `correctionOf: editingRound?.id`.
6. Delete flow: `deleteRound(_:)` calls `scoringService.deleteRound`, reloads
   rounds, reseeds index, clears edit state.
