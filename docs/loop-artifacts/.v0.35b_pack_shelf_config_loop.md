## Task

The settings icon under the Packs card does nothing for Casino or Cards
Against Humanity. `PackShelfReadOnly`'s tap handler (RoomDetailView.swift
~line 1969) guards on `pack.scoringType == .singleWinner`, which blocks
Casino (`.withdrawReturn`) and CAH (`.countBased`). Route each scoring type
to its own config surface: single-winner keeps the payout sheet, Casino
opens the existing `RoomSettingsCasinoSheet`, CAH opens a new
points-per-card sheet.
