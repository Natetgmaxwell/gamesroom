# V0.70 — Microinteractions + haptics pass

User ask (2026-08-14): "let's work on these small things such as
microinteractions, animations, haptics, etc."

V0.42 shipped the first pass (Haptics.swift + pressScale() + seat-claim
ConfettiBurst, commit 8329946). This pass extends it to the surfaces
built since V0.46–V0.68. Do NOT redo what exists — extend.

## Shared foundations (do these first)

### F1. `Haptics.warning()`
Add to `GamesRoom/Views/Components/Haptics.swift`, same shape as the
existing helpers (no-op on macOS via `#if !os(macOS)`):
`UINotificationFeedbackGenerator().notificationOccurred(.warning)`.
Doc comment: "A warning — low-confidence scan result asking for a re-scan."

### F2. `Theme.Motion`
Add a `Motion` enum inside `Theme` (Theme.swift) that centralizes the
timings ALREADY in use in the codebase so new code stops inventing ones:

```swift
enum Motion {
    /// Press feedback — matches PressScaleModifier.
    static let pressSpring = Animation.spring(response: 0.2, dampingFraction: 0.8)
    /// Element insertion/removal (badge in, row out, CTA in).
    static let popIn = Animation.spring(response: 0.3, dampingFraction: 0.7)
    /// Content cross-fades (CTA label flip, caption change, slot state).
    static let fade = Animation.easeInOut(duration: 0.25)
}
```

Do NOT refactor existing call sites to use these tokens (scope creep);
new code in this pass uses them. `Animation` conforms to `Sendable`;
static stored properties on an enum are fine.

## Surfaces

### S1 + S2. Withdraw / Withdraw more (WithdrawChipsSheet.swift)
Both flows open the same sheet via `openWithdraw(event:)`, so one change
covers both.

- In `save()`, on the success path (after `casinoService.withdraw`
  returns, before `dismiss()`): `Haptics.success()`.
- Working-hand badge (`WitnessSlot`, the `if let workingHand` capsule in
  RoomDetailView.swift ~line 1742): add
  `.transition(.scale(scale: 0.85).combined(with: .opacity))` and attach
  `.animation(Theme.Motion.popIn, value: workingHand)` to the badge's
  parent VStack so the capsule springs in when the withdraw lands and the
  state flips to `.inPlay`.

### S3. Dispense (HostWithdrawalsSection, RoomDetailView.swift ~2215)
- Button action: `Haptics.light()` alongside `onDispense(txn.id)`.
- Row removal: each ForEach row gets
  `.transition(.move(edge: .trailing).combined(with: .opacity))`, and the
  rows VStack gets `.animation(Theme.Motion.fade, value: withdrawals.map(\.id))`
  (EventTransaction may not be Equatable; the id array is).
- The section disappears entirely when the last row goes — that collapse
  inherits the parent's existing layout behavior; acceptable.

### S4. Settle scan (ChipScanSheet.swift + CAHCardScanSheet.swift)
Identical treatment in both files:

- Capture: in `processFrame`, right after `isScanning = true`:
  `Haptics.light()` — the shutter-style tick.
- Low confidence: where `lowConfidencePrompt = true`:
  `Haptics.warning()`.
- Confirm: in `confirm()`, success path before `onDone()`/`dismiss()`:
  `Haptics.success()`. Sheet dismissal uses the system's own animated
  dismiss — do not add a custom dismiss animation.

### S5. CTA state flip (WitnessSlot, RoomDetailView.swift ~1772)
The `switch cta` renders two separately-styled buttons; when the state
flips the label snaps. Merge into ONE `Button` so the view identity
persists across the flip:

- Computed `ctaTitle: String` (withdraw → "Withdraw to play", scan →
  `scanTitle`) and the action `cta == .withdraw ? onWithdraw : onScan`.
- Keep the exact existing styling (font, colors, padding, background,
  corner radius, `.padding(.top, 8)`).
- On the `Text(ctaTitle)`: `.animation(Theme.Motion.fade, value: cta)`
  so the label cross-fades instead of snapping. The `CTA` enum has no
  associated values, so it is Equatable without declaration.

### S6. Secondary CTAs animate in (WitnessSlot)
Both `if let onWithdrawMore` and `if let onCAHSettle` blocks:
- Add `.transition(.opacity.combined(with: .move(edge: .top)))` on each
  Button.
- Attach `.animation(Theme.Motion.fade, value: onWithdrawMore != nil)`
  and `.animation(Theme.Motion.fade, value: onCAHSettle != nil)` to the
  outer VStack of WitnessSlot (closures aren't Equatable; the Bool is).

### S7. Mascot footer caption (MascotFooterCaption, ~3237)
When `caption` changes the text swaps invisibly. Make the mascot
"speak":
- On the `Text(caption)`: `.id(caption)` +
  `.transition(.opacity.combined(with: .offset(y: 4)))`.
- Attach `.animation(Theme.Motion.fade, value: caption)` to the same
  Text's container.
- `caption` is a computed String — the `.animation(value:)` needs the
  value to be Equatable, which String is. No behavior change otherwise.

### S8. Season close awards stagger (AwardsCard, ~2007)
Award rows animate in staggered when the card appears:
- Add `@State private var awardsAppeared = false` to AwardsCard.
- On the awards VStack (the `VStack(spacing: 0)` holding the ForEach):
  `.opacity(awardsAppeared ? 1 : 0)` and
  `.offset(y: awardsAppeared ? 0 : 8)`.
- `.onAppear` on that VStack:
  `withAnimation(Theme.Motion.fade.delay(0.05)) { awardsAppeared = true }`
  — a single fade for the whole list. For the stagger, apply per-row
  delay instead: each `awardView(for:)` row wrapped with
  `.opacity(awardsAppeared ? 1 : 0).offset(y: awardsAppeared ? 0 : 6)`
  and drive the state flip with
  `withAnimation(Theme.Motion.fade.delay(Double(idx) * 0.05))` per row
  via a helper that dispatches staggered flips (e.g. a Task that sleeps
  `idx * 50ms` per index, or `.onAppear` with `DispatchQueue.main.asyncAfter`
  per row — pick the simplest that compiles cleanly and is cancellable
  by view teardown; a `Task { try? await Task.sleep(...) }` per row is
  fine).
- Keep it subtle: no scale, no spring, opacity+offset only. No confetti
  (V0.42 confetti stays seat-claim-only).

## Rules (from the brief — violations block merge)
- V0.8: mascot absence during play is the feature. NO ambient motion
  during live play beyond the action's own feedback. Everything here is
  triggered by a user action or a one-shot appear.
- Existing Haptics.swift helpers + Theme tokens only; no new deps.
- One CTA per state; animations must not create competing motion.
- Subtle: table distance, low-light. No confetti outside seat-claim.
