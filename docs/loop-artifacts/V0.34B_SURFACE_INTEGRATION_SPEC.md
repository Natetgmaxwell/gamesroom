## Changes (all in HostScoringDashboard.swift)

### 1. Rounds state + seeding

- Add `@State private var rounds: [EventRound] = []`.
- In `.task` (or onAppear): `rounds = await roomService.loadEventRounds(eventId: event.id)` then `roundIndex = rounds.nextRoundIndex` (seed once; do not clobber a manual adjustment on every refresh — seed only when `roundIndex == 1 && rounds.isEmpty` was the initial state, or track a `didSeed` flag).
- After every successful save/delete: reload rounds, update `rounds`, then `roundIndex = rounds.nextRoundIndex`.

### 2. Timeline section

Insert `SessionRoundTimeline` into the VStack between the submit bar and the
standings strip (or between chip grid and submit bar — pick the layout that
keeps the submit bar adjacent to the chip grid; timeline below submit bar,
above standings). Wrap in `.sectionCard(.standard)` per the component's usage
contract. Inputs:

```swift
SessionRoundTimeline(
    rounds: rounds,
    members: members,
    onEdit: { round in beginEdit(round) },
    onDelete: { round in roundToDelete = round }
)
```

### 3. Edit (correct) flow

- `@State private var editingRound: EventRound?` and
  `@State private var correctionOf: UUID?`.
- `beginEdit(_ round:)`: set `selectedMemberIds = Set(round.entries.map(\.memberId))`,
  `roundIndex = round.roundIndex`, `correctionOf = round.id`, `editingRound = round`.
- Header shows a small "Editing round N — correcting" indicator while
  `editingRound != nil` (caption, muted; use Theme tokens). A "Cancel edit"
  button clears `editingRound`/`correctionOf`/selection.
- `save()`: pass `correctionOf` through to
  `scoringService.recordRoundInput(roomId:eventId:packSlug:input:correctionOf:)`.
  On success: clear `editingRound`/`correctionOf`, reload rounds, seed
  `roundIndex = rounds.nextRoundIndex`.

### 4. Delete (undo) flow

- `@State private var roundToDelete: EventRound?`.
- `.confirmationDialog` (or `.alert`) on `roundToDelete`: "Delete round N?"
  message "This reverses the score change for everyone in the round."
  Confirm → `try await scoringService.deleteRound(roomId:eventId:roundIndex:)`
  → reload rounds → seed nextRoundIndex. Cancel → clear.
- Error → `errorMessage` (existing banner).

### 5. Save refresh

After a successful save (new or correction): reload rounds + leaderboard
(`roomService.loadLeaderboard(roomId:)` if it exists as a load method — check
RoomService; the standings strip reads `cachedLeaderboard`), update `rounds`,
seed nextRoundIndex.
