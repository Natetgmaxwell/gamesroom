# Fix: pack config saves fail silently (CAH points / Monopoly win points)

## Bug
Host edits points-per-card (CAH) or win points (Monopoly) in the config sheet, taps Save, and the value doesn't persist. No error shown.

## Root cause (verified)
The RPC chain is correct and does NOT throw on decode:
- `RoomStore.setRoomPackConfig` calls `execute()` (no type param) which decodes as `Void` via `{ _ in () }` — the JSON-array body is ignored, never throws.
- `RoomService.setRoomPackConfig` already mirrors the override into `packConfigsByRoom` cache (lines 894-897), so the cache IS refreshed.

The real bug is in `RoomDetailView.swift`:
1. `savePayout(packSlug:points:)` (line 2070) swallows the error: `catch { _ = error }`. The comment claims "Service already populated lastError" but `RoomService.setRoomPackConfig` does NOT set `lastError` on failure — it throws. So the error is genuinely lost.
2. Both `PackPayoutSheet` (line 2124) and `CAHConfigSheet` (line 2187) call `onSave(points)` then `dismiss()` synchronously. The sheet closes regardless of whether the save succeeded. On failure the value silently reverts on reopen.

## Fix (all in GamesRoom/Views/RoomDetailView.swift)
1. Change `savePayout` from `async` to `async throws` — remove the do/catch swallow, just `try await roomService.setRoomPackConfig(...)`.
2. Change both sheet `onSave` closure types from `(Int) -> Void` to `(Int) async throws -> Void`.
3. Update the two sheet bindings (lines 1959-1961 and 1973-1975): replace `Task { await savePayout(...) }` with `try await savePayout(...)`.
4. In `PackPayoutSheet` and `CAHConfigSheet`:
   - Add `@State private var isSaving = false`, `@State private var errorMessage = ""`, `@State private var showError = false`.
   - Save button: wrap in `Task { isSaving = true; do { try await onSave(points); dismiss() } catch { errorMessage = (error as NSError).localizedDescription; showError = true; isSaving = false } }`, `.disabled(isSaving)`.
   - Add `.alert("Couldn't save", isPresented: $showError) { Button("OK", role: .cancel) {} } message: { Text(errorMessage) }` to the Form/NavigationStack.
   - Keep Cancel as-is (dismiss without saving).

## Acceptance criteria
- Changing CAH points-per-card and tapping Save → value persists (sheet dismisses only on success).
- Changing Monopoly win points and tapping Save → value persists.
- Re-opening the config sheet shows the saved value (already works via cache mirror).
- If save fails, the user sees an inline error alert and the sheet stays open.
- Tests + parse-checks green (run `./build-and-run-tests.sh`).
