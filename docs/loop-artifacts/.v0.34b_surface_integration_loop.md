## Deliverables (all in HostScoringDashboard.swift)

1. `@State private var rounds: [EventRound] = []`; seed in `.task` via
   `roomService.loadEventRounds(eventId: event.id)`; seed `roundIndex` from
   `rounds.nextRoundIndex` once (track a didSeed flag; don't clobber manual
   adjustments on refresh).
2. `SessionRoundTimeline` section between the submit bar and the standings
   strip, wrapped in `.sectionCard(.standard)`, with `onEdit`/`onDelete`
   wired to the flows below.
3. Edit/correct: tapping a row sets `selectedMemberIds` from the round's
   entries, `roundIndex` to the round's index, `correctionOf` to the round's
   id; header shows a muted "Editing round N — correcting" indicator with a
   Cancel edit button; `save()` passes `correctionOf` through to
   `recordRoundInput(..., correctionOf:)`.
4. Delete/undo: `confirmationDialog` on `roundToDelete` ("Delete round N?",
   "This reverses the score change for everyone in the round."); confirm →
   `scoringService.deleteRound(roomId:eventId:roundIndex:)`; errors surface in
   the existing `errorMessage` banner.
5. After every successful save/delete: reload rounds, update `rounds`, seed
   `roundIndex = rounds.nextRoundIndex`, clear edit state.
