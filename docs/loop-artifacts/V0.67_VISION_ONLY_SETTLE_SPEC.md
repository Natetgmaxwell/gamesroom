# V0.67 — Remove manual settle: vision-only settle path

## Problem (user decision, 2026-08-14)

Remove the option to settle manually and go all-in on the vision system.
Rationale: seamless vision UX + manual entry is an avenue for untruthfulness —
anyone can type any number with no capture to back it.

Vision becomes the ONLY settle path. The in-scan confirm/adjust steppers inside
`ChipScanSheet` + `CAHCardScanSheet` are KEPT — they are attestation of a vision
capture (server keeps the photo hash + VisionSnapshot for dispute matching),
NOT manual settle. `HostScoreEntrySheet` for `.singleWinner` packs is KEPT — that
is round scoring, not settle.

## Target behavior (per role × pack × state)

### Casino member (.inPlay / .settleRound)
- Primary CTA "Settle casino chips" → `ChipScanSheet` (vision). *(unchanged)*
- REMOVE the secondary "Settle manually" link → `SettleCasinoSheet`. *(removed)*

### Casino host (.inPlay / .settleRound)
- Primary CTA "Settle casino chips" → `ChipScanSheet` (vision). *(unchanged)*
- "Score a round" → `ChipScanSheet` (vision). *(unchanged)*
- REMOVE the host manual settle link → `SettleCasinoSheet(isHost:true)`. *(removed)*

### CAH member + host (.inPlay / .settleRound)
- Primary CTA "Count your CAH cards" → `CAHCardScanSheet` (vision). *(unchanged)*
- No manual settle link (count-based has none). *(unchanged)*
- CAH host "Score a round" → `CAHCardScanSheet` (vision). *(unchanged)*
