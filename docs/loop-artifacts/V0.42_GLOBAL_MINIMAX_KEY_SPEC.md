# V0.42 — Global MiniMax API key for LLM functions (not per-user)

## Goal
Replace the per-user MiniMax API key (entered in App Settings) with a single
bundled global key (the app owner's) that powers all LLM functions for all
users. The key lives in `GamesRoom/Config.xcconfig` (gitignored) and is
compiled into the app binary via Info.plist.

## Current state (V0.40)
- `AppSettingsView.swift` has a `SecureField("MiniMax API key")` bound to
  `@AppStorage(StorageKeys.mascotApiKey)`.
- `StorageKeys.swift` defines `static let mascotApiKey = "mascotApiKey"`.
- `NotificationDispatcher.scheduleBriefingTrio` resolves the key via
  `UserDefaults.standard.string(forKey: StorageKeys.mascotApiKey) ?? mascotApiKey`
  (the per-room param), then calls `MascotEngine.generateVoiceLLM(apiKey: ...)`.
- `MascotEngine.generateVoiceLLM` takes `apiKey` as a required param.
- `MascotEngine` already has `defaultLLMEndpoint` and `defaultLLMModel` statics.

## Changes

### 1. Config.xcconfig (DONE — already appended)
```
MINIMAX_API_KEY = "<the real key>"
```
Gitignored. Never commit.

### 2. GamesRoom/Info.plist
Add:
```xml
<key>MINIMAX_API_KEY</key>
<string>$(MINIMAX_API_KEY)</string>
```
Mirrors the existing `SUPABASE_URL` / `SUPABASE_ANON_KEY` wiring.

### 3. MascotEngine.swift
Add a static that reads the bundled key from Info.plist, mirroring the
`SupabaseClientProvider.readConfig` pattern (treat `$(`-prefixed or empty as
missing, fall back to a loud sentinel):
```swift
static let defaultLLMApiKey: String = {
    guard let raw = Bundle.main.object(forInfoDictionaryKey: "MINIMAX_API_KEY") as? String,
          !raw.isEmpty, !raw.hasPrefix("$(") else {
        return "MISSING_MINIMAX_API_KEY_CONFIG_ERROR"
    }
    return raw
}()
```
Change `generateVoiceLLM`'s `apiKey` param to default to `defaultLLMApiKey`:
```swift
apiKey: String = MascotEngine.defaultLLMApiKey,
```

### 4. NotificationDispatcher.swift
Remove the UserDefaults lookup. Resolve the key from the bundled config:
```swift
let resolvedKey = MascotEngine.defaultLLMApiKey
if !resolvedKey.isEmpty && !resolvedKey.hasPrefix("MISSING_") {
    ... generateVoiceLLM(apiKey: resolvedKey, ...)
}
```
Keep the `mascotApiKey` param on `scheduleBriefingTrio` for backward
compat (callers still pass it) but stop reading UserDefaults.

### 5. AppSettingsView.swift
Remove the `@AppStorage(StorageKeys.mascotApiKey)` property and the
"Mascot voice (MiniMax)" SecureField section entirely.

### 6. StorageKeys.swift
Remove `static let mascotApiKey = "mascotApiKey"`.

### 7. main.swift (tests)
- The existing fallback test passes `apiKey: "..."` explicitly — keep it.
- Add a test asserting `MascotEngine.defaultLLMApiKey` is non-empty and does
  NOT start with `MISSING_` (i.e. the bundled key is present in the build).
- Add a test asserting `defaultLLMApiKey` does not equal the sentinel.

## Acceptance criteria
- No API key field in app settings UI.
- Mascot voice uses the bundled key (defaultLLMApiKey), not user settings.
- Config.xcconfig has MINIMAX_API_KEY.
- Tests + parse-checks green.

## Out of scope
- Vision hosted path is dormant (no active service consumes `visionApiKey` in
  the current tree). Not touched. If a future vision service lands, it should
  read `MascotEngine.defaultLLMApiKey` too.
- Backend proxy (v2) — not this task.
