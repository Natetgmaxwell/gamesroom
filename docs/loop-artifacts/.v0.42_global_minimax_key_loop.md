## Task

Replace the per-user MiniMax API key (App Settings SecureField) with a single
bundled global key read from Info.plist (wired from Config.xcconfig). Mascot
voice and any future LLM function read `MascotEngine.defaultLLMApiKey`, not
user-entered settings.

8. Match each file's existing conventions. No dead code, no TODOs, no
