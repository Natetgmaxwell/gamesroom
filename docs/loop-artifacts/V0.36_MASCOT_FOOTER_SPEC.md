# V0.36 — Mascot footer caption driven by room state (kanban t_866b833b)

## Context

User feedback: "The mascot comment down the bottom of the room page doesn't seem to be dynamic. It should be self-aware of the room it's in, and the mascot's personality settings."

Current state (`RoomDetailView.swift` `MascotFooterCaption`, ~line 2143):

- Always calls `MascotEngine.generateVoice` with `kind: .postPlayRecap`
- `activeEventTitle: nil`, `lastEventDaysAgo: nil` — the template's `{event}` placeholder substitutes to empty, so post-play templates render broken text (" has concluded under the host's supervision")
- Only `memberCount` + `memberNames` are real

The caption is a static template that never changes. It doesn't know whether a session is live, who won last, who leads the standings, or how long the room has been quiet.

## Design

### 1. Room state machine (pure, testable)

Add to `MascotEngine`:

```swift
static func footerKind(
    activeEvent: Event?,
    leaderboard: [LeaderboardEntry],
    now: Date = Date()
) -> NotificationKind
```

Resolution order:

| Condition | Kind |
|---|---|
| `activeEvent?.settledAt != nil` | `.postPlayRecap` |
| `activeEvent != nil`, `playedAt <= now` | `.inPlay` |
| `activeEvent != nil` (upcoming) | `.briefingOnCreate` |
| `leaderboard.isEmpty` | `.roomWelcome` |
| last play (`leaderboard.compactMap(\.lastSessionAt).max()`) older than 14 days | `.roomStale` |
| otherwise | `.standings` |

### 2. New `NotificationKind` cases

```swift
case roomWelcome   // no events yet — "First night coming soon"
case inPlay        // active session underway
case roomStale     // quiet > 2 weeks
case standings     // has history, no active event, not stale
```

The existing 4 cases stay. `NotificationKind` is only referenced inside `MascotEngine.swift` (verified: no other file switches on it), so the extension is contained. `buildLLMPrompt`'s `switch kind` gains the 4 new "Message type:" lines.

### 3. `RoomContext` extension (defaulted — existing call sites keep compiling)

```swift
struct RoomContext {
    let activeEventTitle: String?
    let lastEventDaysAgo: Int?
    let memberCount: Int
    let memberNames: [String]
    let recentWinnerNames: [String]   // NEW, default []
    let leaderName: String?           // NEW, default nil
    let callerRank: Int?              // NEW, default nil
    let eventCount: Int?              // NEW, default nil
}
```

Swift's synthesized memberwise init honors defaults, so `NotificationDispatcher.swift:180` (4-arg construction) compiles unchanged.

### 4. New placeholders + nil-safe sentence drop

New placeholders in `interpolate`:

- `{winner}` ← `recentWinnerNames.first`
- `{leader}` ← `leaderName`
- `{caller_rank}` ← `callerRank` (plain number; templates write "You're #{caller_rank}.")
- `{event_count}` ← `eventCount`
- `{days_quiet}` ← `lastEventDaysAgo`
- `{member_count}` ← `memberCount` (fixes latent bug: two existing templates reference it, interpolate never substituted it)

Nil handling change: for the NEW optional placeholders AND `{event}`, when the value is nil leave the `{placeholder}` text in place (do NOT substitute `""`). Then add a sentence-drop pass at the end of `interpolate`:

- Split the output on sentence boundaries (regex `(?<=[.!?])\s+`)
- Drop any segment that still contains a `{` character (an unsubstituted placeholder)
- Rejoin with a single space, then run the existing `collapseWhitespace`

This makes every template nil-safe: a template sentence referencing missing data simply doesn't render. `{mascot}` and `{room}` are always substituted, so they never trigger drops. Existing placeholders (`{time}`, `{venue}`, `{seats_left}`, `{seats_claimed}`, `{host_note}`, `{date}`) keep their current `""` substitution behavior — no regression to existing callers.

### 5. Data derivations (pure, testable)

```swift
/// Names of members who won rounds, most recent round first, deduped, capped at 3.
static func recentWinners(rounds: [EventRound], memberNameById: [UUID: String]) -> [String]

/// First non-host entry (server-sorted by seasonScore desc).
static func leaderName(leaderboard: [LeaderboardEntry]) -> String?

/// 1-based rank among non-host entries; nil when the caller isn't on the board.
static func callerRank(leaderboard: [LeaderboardEntry], currentUserId: UUID?) -> Int?
```

`callerRank` mirrors `StandingsSection.rankFor` (host excluded from numbering).

### 6. View changes (`MascotFooterCaption`)

New `let` properties passed from the parent at the call site (~line 360):

```swift
MascotFooterCaption(
    room: room,
    activeEvent: activeEvent,
    leaderboard: leaderboard,
    currentUserId: currentUserId
)
```

The footer computes:

```swift
private var caption: String {
    MascotEngine.generateVoice(
        mascotName: room.mascotName,
        roomName: room.name,
        personality: room.mascotPersonality,
        ideology: room.mascotPoliticalIdeology,
        kind: MascotEngine.footerKind(activeEvent: activeEvent, leaderboard: leaderboard),
        context: .init(
            activeEventTitle: activeEvent?.name,
            lastEventDaysAgo: daysSinceLastPlay,
            memberCount: members.count,
            memberNames: members.map(\.displayName),
            recentWinnerNames: MascotEngine.recentWinners(
                rounds: roomService.cachedEventRounds(eventId: activeEvent?.id ?? UUID()),
                memberNameById: memberNameById
            ),
            leaderName: MascotEngine.leaderName(leaderboard: leaderboard),
            callerRank: MascotEngine.callerRank(leaderboard: leaderboard, currentUserId: currentUserId),
            eventCount: leaderboard.map(\.sessionsPlayed).max().map { Int($0) }
        )
    )
}
```

- `daysSinceLastPlay`: `Int(Date().timeIntervalSince(lastPlay) / 86_400)` from `leaderboard.compactMap(\.lastSessionAt).max()`, nil when no member has played
- `memberNameById`: `Dictionary(uniqueKeysWithValues: members.map { ($0.userId, $0.displayName) })` (same pattern as `RoundBreakdownSection`)
- `eventCount` is a proxy (max sessions played by any member) — documented as such in a doc comment; nil-safe via sentence drop
- The footer re-renders automatically: `activeEvent`/`leaderboard`/`members` all come from `roomService`'s `@Published` caches
