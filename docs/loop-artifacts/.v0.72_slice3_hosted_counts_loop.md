## Decisions (settled before edits)

1. **Transport**: new `Services/ScanSettleService.swift`. Own `URLSession`
   (request timeout 75s — shared client is 15s and would abort while the edge
   fn's 55s MiniMax call still records). Direct `POST {SUPABASE_URL}/functions/v1/scan-settle`,
   `Authorization: Bearer <access token>` from `SupabaseClientProvider.currentSession()`.
   Reads SUPABASE_URL/ANON_KEY from Info.plist exactly like `SupabaseClientProvider`.
   Response DTOs: chips (`count`,`total_points`,`stacks[{color,count}]`,`photo_hash`,
   `attempt`,`attempts_remaining`) and cards (`count`,`photo_hash`,`attempt`,
   `attempts_remaining`); errors as `{error, reason?}` with status → `ScanSettleError`.
2. **ChipScanSheet rework**: capture (existing `ScanCameraController`) → JPEG(0.8) →
   `scanSettle.submitChips` → read-only result screen (total pts, per-color rows,
   withdrawn + net, photo-hash tail, attempt N of 5, privacy line). No steppers, no
   `ScanConfidenceGate`, no "Review result anyway", no member confirm button — the
   count is recorded by the time the result renders. "Re-scan" → back to camera
   (server latest-wins; 429 surface = "Scan limit reached — ask your host"). Local
   SHA-256 still computed for T1.2 `keepScanPhotos` naming; `persistScanPhoto` unchanged.
   Copy: "Counted by the table's vision service. Counts are final." Privacy: "Your
   photo is analysed by a cloud vision model and never stored."
3. **CAHCardScanSheet rework**: same shape, `submitCards`, count-only result,
   no stepper/no gate. Privacy line same reversal.
4. **Error states** (both sheets, camera screen inline): model_declined /
   unparseable_response / vision_failed / record_failed → "Couldn't read the
   table — retake" (retake affordance); offline (URLError notConnected /
   cannotConnectToHost / timedOut) → "You're offline — check connection";
   429 rate_limited → limit message; 503/5xx → "Scanning is briefly unavailable".
   `Haptics.warning()` on every failure path; `Haptics.success()` when result lands.
5. **DetectionSource**: `case hosted = "hosted"` rawValue is an app-only label;
   DB/edge-fn rows persist source `hosted` in snapshot. Keep `.hosted` for rows
   the app writes via snapshot envelope (matches 069's default extraction), BUT
   decode tolerance: unknown raw values fall back to `.pending` (already the
   pattern). No DB write of `minimax_vision` from the client (069 extracts
   `->>'source'`; edge fn sends "hosted" — canonical, unchanged).
6. **VisionProvider fix**: `case hosted = "minimax_vision"` (DB value canonical,
   spec-mandated). `displayName` "Hosted vision (MiniMax)". Old "hosted" rows
   would now mis-decode — none exist (027 was built-but-disconnected; rooms
   default was on_device until 069). Decoding falls back `.onDevice` for legacy.
7. **Host manual fallback** (`DetectionSource.manual`): absent since V0.67
   (2443f2a deleted SettleCasinoSheet). Add:
   - **Migration 070** (additive): in `record_member_scan` + `record_cah_tally`,
     the minimax_vision gate admits non-service callers who are the room HOST
     (rooms.created_by = caller) AND snapshot source 'manual'. Host may pass
     `p_member_id` (on behalf of a member); host-own recording without
     p_member_id unchanged. Function bodies re-CREATEd (CREATE OR REPLACE keeps
     4-arg signature; no drop needed since args unchanged).
   - **HostManualSettleSheet.swift**: host-only sheet, member picker (cached
     roster) + amount field (chips: points; CAH: card count) + "Record host
     count" → `submitMemberScan(source: .manual, memberId: …)` /
     `recordCAHTally(cardCount:, onBehalfOf:)`. DetectionSource `.manual`.
   - **RoomDetailView**: host-only tertiary "Enter count by hand" button on the
     settle surfaces (`.settleRound` + `.inPlay` WitnessSlot), passes event +
     pack kind. Bounded: one sheet, no redesign.
8. **ChipSegmentationDetector**: sheets stop calling it; file stays (probe tool).
   `ScanConfidenceGate` enum stays in that file — no callers left in sheets.
9. **pbxproj**: new files `ScanSettleService.swift` (0493/0494), 
   `HostManualSettleSheet.swift` (0495/0496) — 4 places each, then
   `python3 scripts/verify-xcode-project.py`.
10. **Tests** (main.swift, Foundation-only): VisionProvider rawValue round-trip
    (on_device / minimax_vision); CasinoConfig decode with `minimax_vision`
    provider; DetectionSource `hosted` rawValue == "hosted"; ScanSettleService
    response decoding (chips + cards + 429 body). ScanSettleService DTO decode
    test added to main.swift.
