## Found (pre-existing, out of scope)

- **RLS policy recursion (42P17)**: rooms↔room_memberships SELECT
  policies mutually recurse — ANY authenticated direct read of
  `events` (and therefore `scan_attempts`, whose host policy joins
  events→rooms) errors with "infinite recursion detected in policy".
  Predates V0.72 (a plain `select from events` under `authenticated`
  fails identically). The app is unaffected because reads go through
  security-definer RPCs, and the edge fn writes via service role. The
  spec's "host sees attempt log" audit board will need this fixed (or
  an RPC wrapper) before any direct client read of `scan_attempts`.
  Flagged for follow-up, not fixed here (out of slice scope).
- db-password in ~/.supabase is stale; `supabase db query --linked`
  (access token) is the working path.
