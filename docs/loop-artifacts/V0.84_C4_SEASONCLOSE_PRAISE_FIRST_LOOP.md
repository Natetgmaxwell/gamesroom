## Discovery (context pass)

The six awards' season-close voice lives in THREE layers, not one:

1. **SQL captions** — `close_season(p_room_id)` writes a `caption` per award row;
   `AwardRow` renders `award.caption` under the recipient's name on the awards
   card. These are the informational "BEFORE" lines:
   - veteran: `Played N session(s) this season.`
   - whale: `Biggest single-session net: +N.`
   - phoenix: `Climbed +N across the season.`
   - drowning: `Kept showing up. The ledger remembers.` (stays private, unchanged)
   - iron_mann: `Attended N consecutive nights.`
   - comeback_kid: `Climbed back N points from the season's low.`
   - good_sport: `Lost well — kept every loss small.`
2. **MascotEngine matrix** — `.seasonClose` (55 cells) is generic season-close
   footer copy, and `.goodSport` (55 cells) is already praise-shaped. The other
   five awards have NO matrix voice cells (footer only ever resolves one kind
   per render).
3. **Edge function** `supabase/functions/mascot-voice/index.ts` — LLM path has
   no season-close branch; `ctx.message_type` never says season-closed.

## The three moves (from the spec — the whole pattern)

1. Name the specific behaviour, not the stat.
2. Praise it sincerely (earned by the act, so it can't be flattery).
3. Keep it about the behaviour, never a blanket "you're great."

Reference AFTER examples (locked in the kanban task):
- Good Sport: "Good Sport: Sam. Three losing nights, and Sam never once tilted,
  never once bailed — kept the loss small and the table laughing. That's the
  player who makes a table worth sitting at."
- Phoenix: "Phoenix: Olivia. Started the season in the hole and clawed all the
  way back — the biggest climb in the room. That's not luck, that's showing up
  and playing it out."
