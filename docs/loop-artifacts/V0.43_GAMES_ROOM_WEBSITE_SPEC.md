# V0.43 — Games Room public website at gamesroom.nateterrence.net

## Goal

Ship a three-page static website for Games Room at
`https://gamesroom.nateterrence.net` (subdomain of Nathan's personal
domain, Cloudflare zone `nateterrence.net`). The site exists to satisfy
the App Store Connect support-URL + privacy-policy-URL requirements
(currently TBD placeholders in `docs/app-store-metadata.md`) and to give
the product a public, honest surface. A move to a dedicated domain
(e.g. `gamesroom.app`) is a later decision — the subdomain is the
interim home and nothing about the build locks the URL in.

## Changes

### 1. Site source — `website/` in this repo

New `website/` directory in the games-room repo (the repo already owns
the content in `docs/`). Plain static HTML + CSS, no framework, no
build step — mirrors the daemon's static philosophy. Three pages:

| Path | Job | Content source |
|------|-----|----------------|
| `/` | Landing | What it is, invite-only, four packs, seasons, mascot. One CTA: "Get the app" (App Store link, added when live) |
| `/support` | App Store requirement | Contact + support surface |
| `/privacy` | App Store requirement | `docs/privacy-policy.md` text, rendered |

No TestFlight signup, no blog, no join-code entry. The product is
invite-only; the site's job is to exist and be honest, not to market.

### 2. Design tokens (locked from brand register)

- Deep indigo base (`#1E1B3A`-family, exact value from V0.38 spec),
  cream text, amber pip (`#F5A623`-family) as the only accent.
- The Four Seats mark (2×2 amber pip grid) as the site header mark.
- Rounded geometric sans (Poppins), wide letterspacing on the wordmark.
- Mobile-first single column; no JS.

### 3. Copy

Landing copy drafted by the writing profile (per profile routing) from
`docs/vision.md` §1 north star + `docs/app-store-metadata.md` working
description. Tone: plain, warm, no hype — matches the app's brand voice.

### 4. Deploy — Cloudflare Pages

1. `wrangler pages project create games-room` (one-time).
2. `wrangler pages deploy website/ --project-name=games-room` (token
   from `~/.hermes/secrets/cloudflare-deploy-token`).
3. DNS: CNAME `gamesroom` → `games-room.pages.dev`, proxied, in the
   `nateterrence.net` zone.
4. No cron — the site changes rarely; deploy on content change.

### 5. Metadata updates

- `docs/app-store-metadata.md`: Support URL →
  `https://gamesroom.nateterrence.net/support`; Privacy policy URL →
  `https://gamesroom.nateterrence.net/privacy`.
- `docs/privacy-policy.md`: update the rendered-URL references from
  `hydrolyze.app/games-room/*` to the new subdomain.

## Acceptance criteria

1. `curl -s https://gamesroom.nateterrence.net/` → 200, landing HTML.
2. `/support` and `/privacy` → 200, correct content.
3. Privacy page text matches `docs/privacy-policy.md` claims.
4. Design tokens match the brand register (indigo/amber/cream, Four
   Seats mark, Poppins).
5. `docs/app-store-metadata.md` + `docs/privacy-policy.md` reference
   the live URLs, no `hydrolyze.app/games-room/*` placeholders remain.
6. No analytics, no tracking, no forms collecting data (privacy policy
   claims "no analytics" — the site must not contradict the app's
   policy).
