## Loop steps

1. **Instrument** (opencode): Perf.swift with os_signpost + DEBUG print
   timing. Wrap: `refresh()` begin/end, each load fn, each CasinoService
   RPC (getMyOpenAttestations, loadWorkingHands, getEventTransactions),
   withdraw + settle actions. No behavior change.
2. **Baseline build + measure** (Mac Studio): build-and-install on iPhone
   17 Pro sim, launch, capture log stream filtered `[GamesRoom] perf`.
   Scenario: cold open → 5s idle → pull-to-refresh → withdraw sheet
   (cancel) → refresh. Record per-load ms.
3. **Fix 1**: remove `Connection: close` (SupabaseClient.swift).
4. **Fix 2**: single-flight loadActiveEvent; 60s throttle on
   close_stale_attestations write; 30s TTL cache on attestations read +
   workingHands + eventTransactions (invalidate on mutations).
5. **Fix 3**: Config.xcconfig SUPABASE_HOST + Info.plist compose +
   readConfig host validation + unquote MINIMAX_API_KEY.
6. **After build + measure**: same scenario, same capture. Compare.
7. **Gates**: ./build-and-run-tests.sh, parse-check, verify-xcode-project.
8. **Cleanup**: remove TEMP V0.62 hooks (ContentView, RoomPage) AFTER
   final measurement.
9. Commit (logical: fix1+2+3+instrumentation separate commits), push.

## Rules

- Measure before AND after. No blind merges of all fixes — if possible
  measure fix-1 alone (biggest suspected win), then fixes 2-3.
- No behavior change: state machine, CTA layout, V0.68 features intact.
- TEMP hooks stay until final measurement (they drive the sim scenario).

## Findings so far (working notes)

- curl: warm HTTP/2 r2-r4 ≈ 23-24ms vs cold ≈ 80-90ms. Conn:close forces
  cold on EVERY rpc.
- refresh(force:true) = 15-17 RPCs; 7 uncached/unconditional; sheet
  dismiss re-fires ALL.
- getMyOpenAttestations fires a WRITE rpc every refresh.
- Cold open: get_active_event ×3 race (no single-flight).
- xcconfig URL truncated to "https: → fallback URL engaged (same value,
  no latency delta). MINIMAX key ships with quote bytes.
